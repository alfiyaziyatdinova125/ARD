# Тема проекта: ARD - Адаптивный и отзывчивый дизайн
Учебный проект по созданию сайта, состоящий из 8 страниц об адаптивном и отзывчивом дизайне.

**Live-сайт:**
https://alfiyaziyatdinova125.github.io/ARD/

## Технологии
- HTML5 — семантическая и валидная разметка
- CSS3 — кастомные стили поверх фреймворка
- Pure CSS 3.0 — CSS-фреймворк ([purecss.io] https://purecss.io/)
- JavaScript — бургер-меню, слайдер карточек, «совет дня»,
  подсветка активного пункта меню
- Git и GitHub Pages — версионирование и деплой

## Запуск
1. Клонируйте репозиторий:
   git clone https://github.com/alfiyaziyatdinova125/ARD.git
3. Откройте index.html в браузере или запустите через Live Server
4. Или просто откройте работающую версию
   https://alfiyaziyatdinova125.github.io/ARD/
